# Quiz Game (Dart CLI)

A simple command-line Quiz Game built using Dart.
This project asks multiple questions, takes user input, and shows the final score.

---

## 🚀 Features

* 10 multiple-choice questions
* User input from terminal
* Instant feedback (correct/wrong)
* Final score display

---

## 🛠️ Tech Used

* Dart (CLI)

---

## ▶️ How to Run

1. Open terminal inside project folder
2. Run:

```
dart run
```

3. Answer questions by typing `a`, `b`, or `c`

---

## 📂 Project Structure

* `bin/quiz_game.dart` → Main game logic
* `pubspec.yaml` → Project configuration

## 🎯 Purpose

This project is made for learning basic Dart concepts like:

* Input/Output
* Conditions (if-else)
